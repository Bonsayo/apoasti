# Astawash (Apoasti)

Astawash is a modern healthcare appointment and registration management system designed for the Ethiopian context. It streamlines the booking flow for patients and provides hospitals with a live dashboard for managing appointments.

## Project Structure

- **/astawash-app**: The core web application built with Next.js, TypeScript, and Vanilla CSS.
- **/docs**: (Root markdown files) Documentation regarding PRDs, wireframes, and UI design.
- **/assets**: (Root PNG files) Design assets and screenshots.

## Key Features

- **Smart Triage**: Helps patients choose the right department based on symptoms.
- **Hospital Selection**: Choose between public and private healthcare facilities.
- **Appointment Tracking**: Real-time status updates (Confirmed, Checked-in, Completed).
- **Admin Portal**: For hospital staff to manage bookings and patient flow.

## Getting Started

To run the application locally:

```bash
cd astawash-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Design
The application features a premium, responsive design with a focus on ease of use and modern aesthetics.
